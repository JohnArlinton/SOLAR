## Summary
The HEJ Site Qualification Program turns 20 candidate sites into one proven pilot: screen fast, evidence the shortlist, model honestly, then pick site number one. The five investment gates in `site-selection` still decide — this program feeds them, it never repeats or replaces them.

## Stages 1–5
| Stage | Action | Output |
|---|---|---|
| 1 — Longlist | List 20 candidate warehouses: NMI, DNSP, roof size and age, tenant, retailer, bills, lease term, landlord | Scored longlist |
| 2 — Evidence | Pull 24 months NEM12 interval data per NMI; roof and structure checks; tenant and lease review; DNSP preliminary enquiry | Evidenced shortlist |
| 3 — Auto calc | Compute annual consumption, daytime share, self-consumption, export, and BESS charge windows per site | Comparable site models |
| 4 — Contact | Engage DNSP + EPC + retailer on the shortlist with real data (load profile, export ask, connection point) | Indicative offers |
| 5 — Model and pick | Run the financial model per site; rank; pick site #1 and advance it through the five gates | One proven pilot |

## Load-first method (authoritative)
1. Start from the NMI: request 24 months of NEM12 interval data.
2. Under 160 MWh/yr in Victoria: request via the retailer or distributor (30-minute data, within 10 days). Over 160 MWh/yr: request via the metering agent.
3. Derive: annual consumption, daytime load, peak demand, weekend and seasonal shape.
4. Size PV to the daytime load (worked example: an 800 MWh/yr site sizes to its daytime band), never to the roof area.
5. If data gaps remain: deploy temporary CT-clamp monitoring (30-second or 1-minute sampling with a historian) before modelling.

## Roof allowances (planning)
| System | Roof allowance |
|---|---|
| 20 kW | About 120–160 m² |
| 100 kW | About 600–800 m² |
| 500 kW | About 3,000–4,000 m² |
| 1 MW | About 6,000–8,000 m² |

- Allow for setbacks, access ways, shading, and structural exclusions on every site; usable roof is always smaller than gross roof.
